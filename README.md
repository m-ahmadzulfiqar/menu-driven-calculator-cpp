# 🧮 Menu-Driven Calculator (C++)

A beginner-friendly calculator developed using C++ as my first programming project.

## 📌 About the Project

This program allows users to perform basic mathematical operations by selecting an option from a menu.

## ✨ Features

- Addition of multiple numbers
- Subtraction of multiple numbers
- Multiplication of multiple numbers
- Division of two numbers
- Square of a number
- Cube of a number
- Input validation
- Division-by-zero handling

## 🛠️ Concepts Used

- C++ Basics
- Variables and Data Types
- If-Else Statements
- For Loops
- Vectors
- User Input and Output
- Basic Arithmetic Operations

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in a C++ compiler.
3. Compile and run `main.cpp`.

Using g++:

```bash
g++ main.cpp -o calculator
./calculator
```

## 🎯 Learning Purpose

This project was created to practice programming fundamentals, logical thinking, and problem-solving in C++.
